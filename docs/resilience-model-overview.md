# Resilience Model Overview

An infrastructure resilience model should organize asset context, exposure, vulnerability, mitigation, continuity readiness, and decision history.

## Core Objects

- Infrastructure asset
- Service dependency
- Exposure record
- Vulnerability record
- Mitigation action
- Continuity readiness check
- Risk score
- Review record

## Model Flow

1. Asset registered
2. Exposure context added
3. Vulnerability factors reviewed
4. Mitigation actions assigned
5. Continuity readiness checked
6. Decision summary generated
7. Review status recorded
8. Record archived for future comparison

## Design Principle

Risk models should support structured decision-making. They should not create false precision or replace expert review.
